# Atribusi dan lisensi fork

Vexora Baileys merupakan fork dari proyek **WhiskeySockets/Baileys**:

- Repositori upstream: https://github.com/WhiskeySockets/Baileys
- Lisensi upstream: MIT
- Dokumentasi upstream: https://baileys.wiki/

## Wajib dipertahankan

1. Jangan menghapus atau mengganti file `LICENSE` asli dari upstream.
2. Pertahankan pemberitahuan hak cipta dan atribusi yang ada di file sumber.
3. Jika mengubah file sumber upstream, jangan mengklaim seluruh karya asal sebagai karya Vexora.
4. Tambahkan catatan perubahan Vexora pada changelog atau catatan rilis.
5. Periksa lisensi dependensi dan aset pihak ketiga sebelum distribusi.

Nama dan logo WhatsApp adalah milik pemilik mereknya. Nama Vexora Baileys tidak menunjukkan dukungan resmi dari WhatsApp atau Meta.
