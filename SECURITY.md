# Kebijakan Keamanan

Jangan melaporkan kerentanan keamanan melalui issue publik.

Untuk sementara, hubungi pemilik repositori melalui fitur kontak privat yang tersedia di profil GitHub atau gunakan fitur pelaporan kerentanan privat GitHub jika diaktifkan.

Dalam laporan, sertakan:
- Ringkasan kerentanan.
- Dampak yang mungkin terjadi.
- Langkah reproduksi yang aman.
- Versi atau commit yang terdampak.

Jangan sertakan file sesi WhatsApp, kredensial, token, atau data pribadi. Hapus atau samarkan informasi sensitif dari log.
